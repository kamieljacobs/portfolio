# Portfolio Kamiel Jacobs

Statische site voor GitHub Pages.

## Opbouw

- `index.html` – algemene portfolio (geen uitgevers of werkgevers genoemd)
- `blokken/` – bouwstenen, elk één keer geschreven: `case-oefenexamens`, `videos`, `lesmateriaal`, `ai-werkwijze`, `over-mij`
- `img/` – schermbeeld en filmafbeeldingen (overgenomen van de biologiesite)
- `p/<code>/` – landingspagina per werkgever, met eigen intro en een keuze uit de blokken
- `assets/` – stijl en het script dat de blokken laadt

## Landingspagina's

Mapnamen zijn bewust neutraal en onraadbaar. Ze worden nergens gelinkt en hebben `noindex`.

## Nieuwe landingspagina

Kopieer een bestaande map onder `p/`, geef hem een nieuwe willekeurige code, pas de intro aan en kies welke `data-blok` regels erin staan en in welke volgorde.

Gele, gestippelde tekst (`class="aanvullen"`) moet nog worden ingevuld.
